# OpenChat для Android — первый установочный APK

В этом каталоге — Android-приложение **OpenChat**, открывающее существующий сайт
https://alexanderkadukov-sys.github.io/file-search2/chat/ без панели браузера.

## Что работает
- Существующие публичные комнаты, сообщения и фотографии через действующий Supabase.
- Выбор файлов и снимков через стандартный Android-диалог, включая камеру (если установлена).
- Сохранение выбранного имени и темы в хранилище WebView.
- Кнопка «Назад» переходит к предыдущему экрану чата, когда это возможно.
- Открытие внешних ссылок в системном браузере.
- Скачивание вложений через системный менеджер загрузок.

## Ограничения
- Нужен интернет: это **WebView-оболочка действующего сайта**, а не офлайн-клиент.
- Личные сообщения Telegram, обычного WhatsApp, личного VK и MAX пока **не интегрированы**.
- Внутри APK нет токенов Supabase service role и других серверных секретов.
- Версия `debug` подписана тестовым Android-ключом. Для выпуска постоянной версии
  требуется отдельный релизный ключ: debug-обновления могут потребовать переустановку
  и привести к потере локального имени/темы (сообщения в Supabase от этого не удаляются).

## Как получить APK без Android Studio
1. Откройте вкладку **Actions** репозитория.
2. Выберите **OpenChat Android APK** → последний успешный запуск.
3. Внизу страницы скачайте артефакт `OpenChat-v0.1.0-Android-APK`.
4. Распакуйте ZIP и установите `OpenChat-v0.1.0-debug.apk`.
5. Для повторной сборки используйте кнопку **Run workflow**.

## Сборка в Android Studio
Открыть каталог `android/`, JDK 17, Android SDK Platform 35, Gradle 8.13.
Используется Android Gradle Plugin 8.13.2. Запустить задачу
`gradle -p android :app:assembleDebug`.

## Безопасность
- Приложение принимает только HTTPS-соединение OpenChat в своём WebView.
- Другие сайты открываются через системный браузер.
- Запрещён загрузчик по HTTP и отключена небезопасная обработка ошибок сертификатов.
- WebView не содержит JavaScript-моста в нативную часть приложения.
- Для будущего личного Inbox нужен отдельный защищённый сервер и проверка разрешений.
