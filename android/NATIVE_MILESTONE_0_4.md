# OpenChat Android 0.4.0 — Native shell + Private Inbox foundation

## Реализовано в этом релизе
- Новая стартовая Activity на Kotlin + Jetpack Compose Material 3.
- Нативная навигация: **Чаты**, **Личные**, **Каналы**, **Настройки**.
- Адаптивные системные отступы `WindowInsets.safeDrawing` и статус/навигационная строка Android.
- Переключение светлой и тёмной темы, настройка сохраняется только в локальных SharedPreferences.
- Публичные комнаты, отправка сообщений, фото, файлов и существующий Supabase открываются из отдельной Java/WebView Activity **без изменения её базы данных и API**.
- Защитная локальная проверка устройства (KeyguardManager: системный PIN/пароль/графический ключ) перед показом **пустой оболочки будущего личного Inbox**; при уходе приложения в фон экран блокируется, `FLAG_SECURE` ограничивает скриншоты открытого личного экрана.
- Честные статусы Telegram/WhatsApp/ВКонтакте/MAX: **не подключено**; никаких фиктивных сообщений и входов.
- Остаётся прежняя проверенная GitHub Actions сборка Android APK с включённым WebView интерфейсом.

## Не реализовано (не путать с подключением)
- Личная авторизация на независимом сервере, серверная база личных сообщений, E2EE или криптографическая защита интеграций.
- Авторизация Telegram (TDLib), вход в личные WhatsApp, VK, MAX, получение/отправка сообщений из этих аккаунтов.
- Полноценная замена текущего публичного WebView нативным Compose-чата: на этом этапе сохраняем рабочую переписку.

## Разделение данных
- Public Chat остается без регистрации и поэтому **не подходит для личных переписок**.
- Private Inbox физически не читает и не пишет таблицы `chat_messages`. Он пустой до подключения отдельно авторизованного бэкенда.
- Локальная проверка PIN — только защита UI на устройстве, **не** серверная аутентификация. Перед синхронизацией обязательно создаётся защищённая серверная граница.
- Ни один токен доступа личных мессенджеров не добавлен в приложение.

## Готовность к выпуску
- CI: Gradle assembleDebug + проверка zip содержимого.
- Проверить на физическом Android: окно над системной строкой не залезает на часы; вход в защищённый раздел, отмена PIN, возврат из public WebView, фото/файлы, тёмная тема.
- Debug APK — не production-подпись. Не гарантируется обновление через переустановку, если использован другой ключ.
